Entry for the [One Emoji, One Smile](https://make.fun/c/u-0xkianno-one-emoji-one-smile-5470751f) bounty on make.fun: send exactly one emoji, the one most likely to make a stranger smile.

## The entry

🤗 — a hugging face. A hug is the warmest thing a stranger can offer at a glance: friendly, universal, clearly chosen rather than the default smiley, with no intimacy or irony.

## How it works

`main.ts` writes the single emoji to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, falling back to `out`), nothing else — no words, no caption, no explanation.
